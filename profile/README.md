# Strong Towns Community Developers & Designers

Open source tools for advocates who do the math. Value-per-acre maps, parking audits and more, built by local groups and shared so any town can use them.

- **Website:** [strongtowns.dev](https://strongtowns.dev)
- **Discord:** [discord.gg/r6erzTuEmn](https://discord.gg/r6erzTuEmn)

## Projects
- [ValuePerAcre2](https://github.com/strongtowns/ValuePerAcre2) maps tax productivity parcel by parcel
- [ParkingLots](https://github.com/strongtowns/ParkingLots) maps surface parking from OpenStreetMap data
- [ssmuhplanner](https://github.com/strongtowns/ssmuhplanner) plans small-scale multi-unit housing on a lot against a BC zoning bylaw
- [ScrollingComparison](https://github.com/strongtowns/ScrollingComparison) makes scrolling before and after videos of roads and neighbourhoods
- [UrbanismYoutubeDiscordNotifier](https://github.com/strongtowns/UrbanismYoutubeDiscordNotifier) posts new urbanism YouTube videos to Discord

Built a tool for your own local conversation? Bring it to the Discord.
